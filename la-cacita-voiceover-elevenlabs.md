## Réglages ElevenLabs v3

- Modèle : Eleven v3. Langue : français. Les tags s'écrivent en anglais, c'est la forme la mieux comprise par le modèle.
- Stability : "Creative" pour la version MC (plus d'expressivité, plus de variation), "Natural" pour la version principale et les stories. Éviter "Robust" ici, il aplatit les tags.
- Voix : choisir une voix dont la description mentionne déjà l'énergie voulue (deep, warm, hype, seductive). Les tags amplifient ce que la voix sait faire, ils ne créent pas un caractère de zéro.
- Générer 3 à 4 prises par version, v3 est volontairement non déterministe. Garder la meilleure.
- Si un tag est lu à voix haute, vérifier qu'il est bien entre crochets droits et suivi d'un espace.
- Tags utilisés : [whispers] [confident] [excited] [mischievously] [shouts] [pause] [short pause]. Autres tags utiles à tester : [laughs] après "personne ne reste dehors", [sighs] avant "Genève... ce samedi", [breathes] pour un souffle avant le titre.
- Les MAJUSCULES forcent l'accent tonique, les points de suspension une micro-pause. Ne pas en abuser sur une même phrase.
- Si la voix écorche un mot, l'écrire phonétiquement : Perreo → "Pérréo", Dembow → "Dèmbo", Bad Bunny → "Bad Beuni", Casita → "Cassita".
